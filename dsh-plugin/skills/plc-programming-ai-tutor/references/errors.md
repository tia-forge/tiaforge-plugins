# 报错对照表

> 用法：学员贴报错 → **先让他把原文整行贴出来**（不要截图里的半句）→ 在这里找关键词 → 给一级提示。
> 界面语言不同，同一错误的文字会有差异，所以**按关键词认，不按整句认**。

---

## 一、三条原文已核实的（可直接照抄给学员）

### 1. `Parameter 'PT' has to be used.`

- **什么时候出现**：调用 `TON` / `TOF` / `TP` 时，某个调用没给 `PT`。最常见的是复位分支里写成 `#PulseA(IN := FALSE);`
- **什么意思**：计时器每次调用都必须带满参数，包括"只是把它复位一下"的那次调用。
- **改法**：一个扫描周期只调用一次计时器，把复位条件并进 `IN`：
  ```scl
  #PulseA(IN := #RunningState AND #SensorA AND NOT #PulseB.Q AND NOT #Reset,
          PT := T#2S);
  #DiverterA := #PulseA.Q AND NOT #Reset;
  ```
- **判据**：改完编译 0 错误；用例里"复位后不再动作"这条要过。

### 2. `The parameter '#Running' might not be initialized.`（警告）

- **什么时候出现**：某个输出/变量在读取之前没有被确定赋值——典型是只在 `IF` 里赋值，其他分支不赋值。
- **什么意思**：编译器不确定它有没有值。**这是警告，但别放过**——它指向的是"你没想清楚所有情况"。
- **改法**：用一个静态变量承载状态，**块尾无条件赋值**：
  ```scl
  #RunningState := ...;   // 中间逻辑只改状态
  #Running := #RunningState;   // 块尾统一输出
  ```
- **判据**：编译 0 错误 **0 警告**；每个输出在块里都能找到一条无条件的赋值路径。

### 3. `No device with PLC software was found in the project.`

- **什么时候出现**：往一个**空项目**里导入块，或让工具往项目里写东西。
- **什么意思**：项目里没有带 PLC 软件的设备（CPU），所以没有地方放你的块。
- **改法**：先加一台 CPU（添加新设备 → S7-1200 / S7-1500）。**不需要真实硬件。**
- **判据**：项目树里出现 `PLC_1 [CPU ...]`，展开能看到"程序块"。

## 二、按关键词查（文字随界面语言变化）

| 报错里会出现 | 什么意思 | 先查什么 |
|---|---|---|
| `Undefined tag` / 未定义变量 / 符号未定义 | 变量没在变量表里建，或拼错了 | 默认变量表里有没有这个名字；大小写不敏感但拼错不认 |
| `Cannot convert` / 类型不匹配 | 把 `Int` 塞进 `Bool`，或 `Real` 和 `Int` 直接算 | 两边类型是否一致；`Int` 转 `Real` 要显式转 |
| `Instance DB` / 背景数据块 缺失 | FB 调用时没建背景 DB（多重实例没在 Static 里声明） | 调用 FB 时是否选了"单个实例"；多重实例要写在 Static 区 |
| `not consistent` / 不一致 | 块被改过但没重新编译，或调用关系断了 | 右键程序块 → 编译 → 软件（全部重建） |
| `Coil is used more than once` / 线圈重复 | 同一个输出在多个网络里被线圈驱动（双线圈） | 全工程搜这个输出名，只留一处驱动 |
| `Cannot reach` / 无法到达设备 | 下载时 CPU 不可达 | 仿真是否已启动；IP 是否同网段；网线/虚拟网卡 |
| `The module cannot be reached`（仿真时） | PLCSIM 没启动或没转到在线 | 工具栏"开始仿真"→ 启动 → 再下载 |
| `Access denied` / 没有权限 | 工程被别的实例占用，或文件只读 | 关掉重复打开的博途；检查文件属性 |
| 编译成功但下载报错 | 编译的是"软件"，硬件组态没编译 | 右键设备 → 编译 → **硬件（全部重建）** |
| 变量能看不能改（监控表灰色） | 没在线，或该变量被程序每周期重写 | 转到在线；检查是不是被线圈驱动 |

## 三、判分怎么用这张表

1. **学员自己查表找到的，记 PASS**（查错能力本身就是这一层要练的）。
2. **教练直接告诉答案的，记 `PASS(抄)`**，下次换个错让他自己查。
3. 同一个错出现三次 → 不是粗心，是概念没通，回退一层。

---

## 四、三条铁律

1. **没有原文不判。** "报错了"不算证据，要整行。
2. **一次只修一个错。** 十个报错先修第一个——后面的往往是被它带出来的。
3. **修完必须重新编译并重跑用例。** 编译过了不等于逻辑对，这条在 L2 之后尤其重要。
