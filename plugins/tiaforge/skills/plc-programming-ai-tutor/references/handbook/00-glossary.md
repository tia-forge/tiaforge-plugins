# 术语最小集（18 个词）

> 用法：学员问"这是什么"时，先给「一句话」，他还不懂再给「类比」。**一次最多讲三个词**，讲多了记不住。
> 判据：他能用自己的话复述一遍，就算过了。

## 一、程序是怎么跑的

| 词 | 一句话 | 类比 |
|---|---|---|
| **扫描周期** | 读输入 → 跑一遍程序 → 写输出，循环不停 | 心跳。每秒几百上千次 |
| **OB1** | 主程序块，每个扫描周期从头跑一遍 | 总调度，一圈一圈转 |
| **输入映像** | 程序读的是周期开始时的输入快照，不是"此刻的端子" | 每圈开工前拍一张现场照片 |
| **输出映像** | 程序写的是缓冲区，周期末尾才真正送到端子 | 下班前统一发货 |

**最关键的一句**：程序不是执行一次就结束，是**每秒重复几百上千次**。所有"为什么它自己又起来了"的问题，都从这里找答案。

## 二、四种块（最容易混）

| 块 | 一句话 | 有没有记忆 | 类比 |
|---|---|---|---|
| **OB** | 组织块，谁在什么时候调用它 | 无 | 排班表 |
| **FB** | 功能块，**带静态变量**，能记住上次的值 | **有** | 一台有记忆的设备 |
| **FC** | 函数，**没有静态区**，每次进来都是新的 | 无 | 一张计算纸 |
| **DB** | 数据块，存数据；FB 的"记忆"就存在它的背景 DB 里 | 有 | 抽屉 |

**判据**：能用一句话说清"为什么定时器要放 FB 不能放 FC"（答：FC 没有静态区存不住实例）。

## 三、编译与运行

| 词 | 一句话 | 类比 |
|---|---|---|
| **编译** | 把程序翻成 CPU 能执行的东西，同时查错 | 交卷前检查 |
| **下载** | 把编译好的东西送进 CPU | 把文件拷进机器 |
| **在线 / 离线** | 在线 = 连着 CPU 看实时值；离线 = 只看程序 | 看直播 vs 看录像 |
| **仿真（PLCSIM）** | 用软件假装一台 CPU，不需要真实硬件 | 飞行模拟器 |
| **监控表** | 一张能强制改变量、看实时值的表 | 试验台上的手动开关 |

## 四、变量与地址

| 词 | 一句话 | 类比 |
|---|---|---|
| **符号名 / 地址** | 地址是 `%I0.0`，符号名是 `Start`；程序里**只用符号名** | 门牌号 vs 房间名 |
| **I / Q / M** | I = 输入，Q = 输出，M = 中间继电器（内部变量） | 进线 / 出线 / 草稿纸 |
| **变量表** | 把符号名、地址、类型登记在一起的那张表 | 通讯录 |
| **UDT** | 自定义数据类型，把几个变量打包成一个 | 一个文件夹 |
| **保持性** | 断电后值还在。默认不保持 | 便签 vs 白板 |

## 五、两个最容易被误用的词

| 词 | 常见误用 | 正确理解 |
|---|---|---|
| **"扫描周期"** | 以为是"程序跑完一轮的总时间" | 是**一轮的开始到下一轮开始**；程序执行只占其中一小段 |
| **"编译通过"** | 以为等于"逻辑对" | 只说明类型和语法没问题。逻辑对不对，要靠用例 |

---

## 怎么用这份表

1. 学员问到某个词 → 只讲他问的那个，别顺手扩展。
2. 每层开始时挑 2–3 个词抽查，答不上来就先补，不要硬往前走。
3. 术语只在第一次出现时解释，第二次起直接用——**不要每次都重新解释**，那会让学员觉得自己一直在原地。
