# L1.2 读一段 5 网络的图

> 教练读法：这一课**只读不写**。给图，让他说；说错了先问"你是从哪个符号看出来的"，别直接纠正。

---

## 0. 这节课要得到什么

拿到一段陌生的梯形图，能按固定顺序说出三句话：

1. **它在等谁**（哪个输入）
2. **满足什么条件**（串联/并联/边沿/定时）
3. **谁动**（哪个输出）

能说出这三句，再加上一句"这段图的目的是什么"，就算读懂了。

---

## 1. 读图的固定顺序（教他这个顺序，别让他乱看）

| 步 | 做什么 | 为什么 |
|---|---|---|
| ① 先看右边 | 找所有线圈/置位/输出 | 输出决定了这段图"想干什么" |
| ② 从右往左倒推 | 顺着线往左走，问"要让它通，需要哪些条件都成立" | 串联 = 与，并联 = 或 |
| ③ 找"谁在写同一个东西" | 全段搜这个输出名 | 双线圈是最常见的坑 |
| ④ 看有没有时间/边沿 | `TON`、`P`、`N` | 有时间的图，行为随周期变 |

**顺序不能反。** 从左往右看的人，会被细节带跑。

## 2. 练这张图

```text
网络 1  启动自锁
      Start        Stop                      Run
──┤ ├──┬──────┬──┤/├────────────────────────( )──
       └─┤ ├──┘        （并联填 Run）

网络 2  输送机跟着运行
      Run          Auto                     Conv1
──┤ ├──────────┬────────────────────────────( )──
                │
网络 3  到料检测
      Conv1       SensorA                    PartAt
──┤ ├──────────┴────────────────────────────( )──

网络 4  推料（延时 2 秒）
      PartAt       Manual                    TON_A
──┤ ├──────────┬──────────────────────────────┤
                │                          IN   PT
                │                          T#2S
网络 5  气缸输出
      TON_A.Q     Auto                     CylA
──┤ ├──────────┴────────────────────────────( )──
```

---

## 3. 你要交的东西

用**四句话**写出来（不许贴代码，不许复述图）：

1. 这段图在等谁：______
2. 满足什么条件它才动：______
3. 谁动：______
4. 这段图的目的是：______

再加一条：

5. 网络 4 里 `Manual` 是常闭触点，这意味着什么？（提示：手动模式下会发生什么）

**判据**：

- 四句话里每个条件都能指到图上具体一个符号；
- 第 5 问答对（`Manual` 常闭 = 手动模式时**不**延时推料，这是常见的"手动不自动"写法）；
- 说不出"目的"的，算没过——只翻译符号不叫读懂。

---

## 4. 常见失败与提示

| 现象 | 一级提示 | 二级提示 |
|---|---|---|
| 从头开始逐个符号念 | 先看右边：谁在动？ | 从线圈倒着走 |
| 把中间变量当输入讲 | `Run` 是自己写的还是外面来的？ | 搜它在哪里被赋过值 |
| 漏掉并联支路 | 有几个条件可以分别让它通？ | 并联 = 或，逐条列 |
| 把 `Manual` 常闭当成"手动时动作" | 常闭触点什么时候通？ | 变量 = 0 时通 |

---

## 5. 收尾

> **"读图从输出倒着走：要它动，需要哪些条件同时成立。"**
