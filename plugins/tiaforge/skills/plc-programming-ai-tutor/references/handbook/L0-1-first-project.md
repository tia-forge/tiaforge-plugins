## 1. 做四件事

### ① 新建项目

- 项目名：`Demo_First`（英文，不要中文）
- 路径：`D:\PLC\Demo_First`（**不要有中文和空格**）

### ② 加一台 CPU

- 项目树 → **添加新设备** → 控制器 → SIMATIC S7-1200 → CPU 1214C DC/DC/DC
- **不需要真实硬件。** 没有 CPU，程序没地方编译。

### ③ 在 OB1 里写一个线圈

双击 **程序块 → Main [OB1]**，拖一个线圈 `( )` 到第一个网络，左边直接连母线：

```text
                                                  Q0.0
──────────────────────────────────────────────────( )──
```

填地址 `%Q0.0`（或先建符号名 `Led`，类型 Bool，地址 `%Q0.0`）。

**这一行代码的意思**：每个扫描周期都无条件把 `Q0.0` 置 1。

### ④ 编译

右键 **程序块** → **编译** → **软件（全部重建）**。

```text
0 错误, 0 警告
```

## 2. 你要交的东西

| # | 交什么 | 怎么算过 |
|---|---|---|
| 1 | 编译结果 | `0 错误, 0 警告`（贴原文一行） |
| 2 | 项目树截图或文字描述 | 能看到 `PLC_1 [...]` 和"程序块" |
| 3 | 一句话回答 | "OB1 多久执行一次？" |
| 4 | 一句话回答 | "为什么 `Q0.0` 会一直亮，而不是亮一下就灭？" |

第 3、4 题是本课的真正判据。**答不上来，说明扫描周期这个概念还没建立，别往下走。**

参考答案（PASS 之后再给）：

- OB1 每个扫描周期执行一次，每秒几百上千次。
- 因为它不是"亮一次"，是**每一圈都被重新点亮一次**。

## 3. 常见失败与提示

| 现象 | 一级提示 | 二级提示 |
|---|---|---|
| 编译按钮是灰的 | 项目里有 CPU 吗？ | 添加新设备 → S7-1200 |
| 报"未定义变量" | `Q0.0` 有没有登记在变量表？ | 直接在触点/线圈上填 `%Q0.0` 也能编译 |
| 编译过了，仿真里灯不亮 | 下载了吗？转到在线了吗？ | 工具栏"开始仿真"→ 启动 PLCSIM → 下载 → 转到在线 |
| 灯在闪 | 你写的是不是定时器或边沿？ | 这一课应该只有一个线圈 |
| 找不到"开始仿真" | 装 PLCSIM 了吗？ | 没装就走云端仿真，逻辑一样 |

---

## 4. 为什么这一课重要

后面所有"它怎么不按我想的动"的问题，都要回到这一课：

- 程序**每一圈**都在重新决定输出。
- 所以"保持"是靠逻辑保持的，不是靠"上次的状态"。
- 所以一个地方写错，下一圈就立刻体现出来。
