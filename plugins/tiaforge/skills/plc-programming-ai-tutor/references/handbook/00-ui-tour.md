# 博途界面：四个区，一个搜索法

> 用法：**五分钟看完这一页，别背。** 后面找不到东西就回来查第 2 节。
> 为什么不列菜单清单：菜单文字随版本和界面语言变（V19/V20/V21、中/英文），背下来三天就忘。**认区域 + 会搜，比背菜名管用十年。**

---

## 1. 四个区（L0–L5 的所有操作都在这四处）

```text
┌─────────────┬──────────────────────────────┬─────────────┐
│  ① 项目树   │        ② 工作区              │ ③ 巡视窗口  │
│  （左）     │        （中）                │  （右）     │
│             │                              │             │
├─────────────┴──────────────────────────────┴─────────────┤
│                    ④ 信息 / 诊断窗口（下）                │
└──────────────────────────────────────────────────────────┘
```

| 区 | 叫什么（中 / 英） | 干什么 | 什么时候会用到 |
|---|---|---|---|
| ① | 项目树 / Project tree | 找设备、找块、找变量表、找监控表 | **每一课**。所有"双击打开"都在这里 |
| ② | 工作区 / Work area | 写程序、看设备视图、看拓扑 | 写块、画梯形图、组态硬件 |
| ③ | 巡视窗口 / Inspector window | 看/改属性、看信息、看诊断 | 改变量属性、查块属性、看交叉引用 |
| ④ | 信息窗口 / Info window | **编译结果和报错在这里** | 每次编译。判分要的"编译输出原文"就从这里复制 |

**一句话记住**：**左边找东西，中间干活，右边改属性，下面看报错。**

### 新手最容易找不到的三个东西

| 想找 | 在哪 | 怎么到 |
|---|---|---|
| **编译结果** | ④ 下方窗口的"信息 → 编译"（Info → Compile） | 编译完自动出现；关掉了就再编译一次 |
| **交叉引用** | ③ 巡视窗口（选中块后）或右键菜单 | 右键块 → 交叉引用（Cross-references） |
| **监控表** | ① 项目树 → 监控与强制表（Watch and force tables） | 里面没有就右键新建一张 |

## 2. 一个搜索法（这一页最值钱的部分）

博途右上角有个**命令搜索框**（放大镜图标，Search commands）。输入关键词，直接跳到那个命令——**不用在菜单里翻**。

| 你想干什么 | 搜这个（中 / 英） |
|---|---|
| 加一台 CPU | 添加新设备 / Add new device |
| 编译程序 | 编译 / Compile |
| 下载到 CPU | 下载到设备 / Download to device |
| 找变量在哪用了 | 交叉引用 / Cross-references |
| 打开监控表 | 监控与强制表 / Watch and force tables |
| 启动仿真 | 开始仿真 / Start simulation |
| 查这条指令 | 按 **F1**（选中指令直接跳帮助） |

**教他的不是"菜单在哪"，是"搜一下"这个习惯。** 版本升级、换语言、换机器，这招永远有效。

---

## 3. 三个界面习惯（省掉一半麻烦）

1. **项目树永远别关。** 关了在"视图 → 项目树"里打开，但多数人关了就找不回来。
2. **窗口乱了就重置布局**：视图菜单里有恢复默认布局的选项（各版本名字不同，搜"布局 / layout"）。
3. **不要装第三方工具栏插件**。学的时候界面越干净越好，多一个图标多一分混乱。

## 5. 教练的提醒

- **不要逐项介绍菜单**。绝大多数菜单项他一辈子用不到，介绍等于制造噪音。
- 他问"这个按钮是干嘛的"→ 反问"你现在想干什么"，然后教他搜那个词。
- 界面问题一律 30 秒内解决，解决不了就跳过——**界面不是学习目标，是路过的工具**。
