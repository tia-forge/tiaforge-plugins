argument-hint: "[设备名; CPU 型号; 槽位表，例如 Line1_PLC; CPU 1511-1 PN; 2=DI16,3=DO16]"
---

按 `$ARGUMENTS` 里的设备名、CPU 型号与槽位表，在博途里完成硬件组态。

执行顺序（不要跳步）：
1. **确认现场**：连上网关，确认目标工程已打开、目标设备名是否已存在（重名就停下问我）。
2. **CPU 选型**：在硬件目录里搜索该 CPU 型号，列出候选（订货号 + 固件 + 接口/内存差异），**只从搜索结果里选，不凭记忆写订货号**；选定后先告诉我选的理由，等我确认。
3. **预演**：确认设备名、设备类型、分组不冲突。
4. **创建 CPU**（此时才产生机架与 PLC 软件）。
5. **按槽位插入模块**：一槽一步，每步报「槽号 / 模块 / 订货号」。
6. **分配 IP / 子网 / IO 系统**。
7. **编译**，把编译输出原文贴出来。
8. **读回硬件树**，与第 1 步的槽位表逐行对照，给出差异表。

红线：
- 不碰生产设备、不下载到真机（本次只做组态与编译）；
- 任何"已完成"的结论都必须有**编译输出或读回结果**支撑，否则说"未验证"。
