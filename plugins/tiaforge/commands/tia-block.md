---

按 `$ARGUMENTS` 建块并实现逻辑。

执行顺序：
1. 读块清单，确认目标块名/编号未被占用（重名就停下问我）。
2. **先定接口**：把 IN / OUT / IN_OUT / STATIC / TEMP 逐项列给我确认（名称 / 方向 / 类型），我不要猜。
3. 写实现（语言按上面指定；如果指定 SCL，就用 SCL）。
4. **编译**，把编译输出**原文**贴出来。
5. 编译通过后**读回接口**，按「名称 / 方向 / 类型」三列贴出，与第 2 步对照。
6. 最后列出你实际调用了哪几个工具（工具名 + 关键参数），我要能复现。

规则：
- 不许把"我写好了"当结果；成功 = 编译输出说成功；
- 编译报错时只改代码，不要改接口约定（接口要变先问我）；
- 涉及安全功能（急停/安全门/光幕）一律不生成，改为提示"这部分必须硬件实现"。
