# L1.1 认元件：五个符号，一张表

> 教练读法：这一课**不写代码**，只认符号。让他填表，填完就算过。别一边认一边写，会混。

---

## 0. 这节课要得到什么

看到一段梯形图，能指着每个符号说出：它是"条件"还是"结果"，通了代表什么。

---

## 1. 五个元件

| 符号 | 名字 | 什么时候"通" | 常见误用 |
|---|---|---|---|
| `┤ ├` | 常开触点 | 变量 = 1 时通 | 以为它是"按钮"，其实它只看变量值 |
| `┤/├` | 常闭触点 | 变量 = 0 时通 | 以为它等于"取反输出"，其实只是条件取反 |
| `( )` | 线圈 | 左边整条通，它就 = 1 | 同一个线圈写两处（双线圈） |
| `(S)` / `(R)` | 置位 / 复位线圈 | 左边通时置 1 / 置 0，**之后一直保持** | 置位了没人复位，输出永远不下来 |
| `┤P├` / `┤N├` | 正/负边沿触点 | **只在跳变的那一个扫描周期通** | 以为它会持续；实例放在被多次调用的块里 |

**一句话区分**：触点看的是"值"，`P`/`N` 看的是"变化"，线圈写的是"结果"。

```text
      Reset                                LampOut

```

## 4. 两道必答题

1. **`Stop` 是常闭触点，那按下停止按钮时，它是通还是断？**
   （答案方向：按下 = 变量变 1 = 常闭触点断 → 网络断 → `Run` 掉。）
2. **网络 2 和网络 3 都在写 `LampOut`，这算不算双线圈？**
   （不算。`S`/`R` 是"保持型写入"，和线圈不同；但如果同一处既用线圈又用 S/R，就要小心顺序。）

---

## 5. 常见失败与提示

| 现象 | 一级提示 | 二级提示 |
|---|---|---|
| 把常闭触点当成"输出取反" | 它是条件还是结果？ | 触点都在左边，线圈在右边 |
| 说不清 `P` 触点通多久 | "边沿"两个字是什么意思？ | 只在一个周期通 |
| 以为置位会自动复位 | 谁负责把它清掉？ | 必须有人写 `(R)` 或赋值 0 |
