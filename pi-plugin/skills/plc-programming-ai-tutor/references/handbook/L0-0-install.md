# L0.0 装不上怎么办

> 这一页不是课，是**分流**。小白最容易在这里卡住：还没写一行代码，先被安装卡三天。
> 教练的任务：十分钟内判断他走哪条路，然后立刻开始 L0.1，别让他在安装上耗掉热情。

---

## 一、先问三个问题（一次问完）

1. 你电脑是 Windows 10/11 吗？（博途只有 Windows 版）
2. 磁盘还剩多少空间？（安装包和解压后都要占很大一块）
3. 你有能打开 `.ap19` / `.ap20` 这类工程文件的环境吗？（有 → 他其实已经装好了）

按答案走下面三条路。

---

## 二、三条路

| 路 | 适合谁 | 代价 | 能走到哪一层 |
|---|---|---|---|
| **A. 装博途** | 有 Windows 机器、打算长期学 | 装一次要几个小时，占空间大 | 全部（L0–L5） |
| **B. 云端仿真** | 装不上 / 没授权 / 只是想先试试 | 只能跑 SCL 逻辑，看不到梯形图界面 | L0–L3 |
| **C. 借环境** | 公司或学校有机器 | 要凑时间 | 全部 |

**关键判断**：如果他今天只想"试试看值不值得学"，走 B，十分钟就能跑起第一段逻辑。**不要让他为了试一下先装三小时。**

---

## 三、走 A（装博途）时，先避开五个坑

1. **路径不要有中文和空格。** 装在 `D:\TIA`，不要 `D:\我的软件\博途 V19`。
2. **安装前关掉杀毒软件的实时防护**（装完再开）。中途被拦一半是最麻烦的状态。
3. **安装过程很长**，中间会要求重启；重启后要**继续安装**，不是重新装一遍。
4. **装完先别急着找许可证**。先新建一个空项目、加一台 CPU、编译一次——**能编译就说明环境是好的**，这一步比许可证更早。
5. **版本和工程要对上**：别人给的工程是 V19 的，你的博途至少要是 V19（高版本能开低版本，反过来不行）。

> 遇到报错先去 `references/errors.md` 查关键词，别直接搜百度——搜出来多半是无关的安装教程。

---

## 四、走 B（云端仿真）时，怎么练

不需要装博途，也不需要真实 CPU：

1. 用文本写一段 SCL（哪怕只有 `IF` 和赋值）。
2. 交给云端仿真跑：给一组输入，看输出是不是你要的。
3. 拿 PASS/FAIL 报告当判据。

**这一路的边界**：看不到梯形图界面、不能用监控表、不能下载到真机。所以 L1（读图）要用文字描述的图来练，L4（读老工程）走不了。

---

## 五、这节课的判据（三条路都适用）

- [ ] 能新建（或打开）一个项目
- [ ] 项目里有一台 CPU（不需要真实硬件）
- [ ] 能编译出 `0 错误, 0 警告`
- [ ] 能说出自己走的是 A / B / C 哪条路，以及这条路走不到哪一层

四条全过，进 L0.1。

---

## 六、教练的提醒

- **不要在安装上陪跑超过 20 分钟。** 超过就切 B，先把第一课跑通，安装留到课后。
- 他抱怨"这软件太难装"时，不要安慰，直接给路：「先走 B，今天就能跑起来；装的事周末弄。」
- 装完第一件事不是打开教程，是**编译一次**。这个动作会把"环境问题"和"学习问题"彻底分开。
