# L2.1 互锁：正反转

> 教练读法：这一课第一次出现"会出事的错"。判 FAIL 时先问一句："如果两个接触器同时吸合会怎样？"让他自己说出后果，比讲十遍规则有用。

---

## 0. 这节课要得到什么

一个正反转控制：按正转就正转，按反转就反转，**任何时候都不许两个一起动**。

现场含义：正反转两个接触器同时吸合 = 相间短路。这不是"程序不好看"，是**炸设备**。

---

## 1. 需求（先写清，再写码）

| 项 | 内容 |
|---|---|
| 输入 | `Fwd`（正转按钮）、`Rev`（反转按钮）、`Stop`（停止按钮，常闭接法） |
| 输出 | `QF`（正转接触器）、`QR`（反转接触器） |
| 规则 | 同一时刻最多一个输出为 1；两个按钮同时按 → **都不动**（安全优先） |
| 停止 | `Stop` 按下 → 两个都掉 |

**"同时按都不动"是约定，不是物理规律。** 也有设备要"后按的优先"，那是另一种约定，要跟现场确认。默认取安全的那一种。

---

## 2. 梯形图（照抄）

```text
网络 1  正转
      Fwd          Stop        QR          QF
──┤ ├──┬──────┬──┤/├──┬──┤/├──┬──────────( )──
       │      │        │      │
       │  QF  │        │      │
       └─┤ ├──┘        │      │
                       └──────┘   ← 互锁：反转在动时，正转不许通

网络 2  反转
      Rev          Stop        QF          QR
──┤ ├──┬──────┬──┤/├──┬──┤/├──┬──────────( )──
       │      │        │      │
       │  QR  │        │      │
       └─┤ ├──┘        │      │
                       └──────┘
```

**关键**：互锁的常闭触点 `┤/├` 串在**输出的条件里**，不是串在按钮上。

---

## 3. SCL 写法（对照着看）

```scl
IF #Stop THEN
    #QF := FALSE;
    #QR := FALSE;
ELSE
    #QF := #Fwd AND NOT #QR;
    #QR := #Rev AND NOT #QF;
END_IF;
```

⚠️ 上面这段**有个坑**：`#QF` 用了 `#QR` 的旧值，`#QR` 又用了 `#QF` 的新值——两个输出在同一周期里"接力"，可能一个都起不来。正确做法是先算中间状态，块尾统一输出：

```scl
#FwdCmd := #Fwd AND NOT #Rev AND NOT #Stop;   // 同时按 → 都不动
#RevCmd := #Rev AND NOT #Fwd AND NOT #Stop;
#QF := #FwdCmd AND NOT #QR;                  // 用上一周期的状态做互锁
#QR := #RevCmd AND NOT #QF;
```

**这就是"块尾统一赋值"这条规矩的来历**——不是为了整齐，是为了让互锁读到的值是可预期的。

## 4. 你要交的东西

| # | 用例 | 期望 | 实际 | PASS/FAIL |
|---|---|---|---|---|
| 1 | `Fwd`=1 → 0（松手） | `QF` 保持 1 | | |
| 2 | 正转中按 `Rev` | `QF` 先变 0，`QR` 再变 1（或有明确间隔） | | |
| 3 | `Fwd`、`Rev` 同时按 | `QF`、`QR` **都是 0** | | |
| 4 | 运行中按 `Stop` | 两个都变 0 | | |

**判据**：

- 编译 0 错误 0 警告；
- 四条用例全过；
- **能用一句话说出"两个接触器同时吸合会怎样"**（说不出 → 不算过）。

---

## 5. 常见失败与提示

| 现象 | 一级提示 | 二级提示 |
|---|---|---|
| 同时按时一个动了 | 同时按应该发生什么？ | 两个命令互相要"看对方" |
| 互锁写在按钮上 | 按钮断开和输出断开，哪个更可靠？ | 互锁要串在输出条件里 |
| 切换瞬间两个都亮了一下 | 你在同一个周期里改了几个输出？ | 先算状态，块尾统一赋值 |
| 停止按钮不起作用 | `Stop` 是常闭接法吗？ | 现场常闭 = 变量为 1 时"按下" |
| 反转起不来（永远互锁） | 互锁读的是自己还是对方？ | `QF` 要读 `NOT #QR`，不是 `NOT #QF` |

---

## 6. 为什么

1. **为什么互锁必须写在输出上？** 按钮是人的操作，输出是设备的状态。人可能同时按两个，设备状态不能同时成立。
2. **为什么"同时按都不动"？** 因为"哪个先"是不可靠的。凡是依赖"谁先谁后"的安全逻辑，现场一定会出问题。
3. **为什么接触器还要硬件互锁？** 程序里的互锁只在程序正常时有效。硬件互锁（辅助常闭触点串联）是最后一道防线，**两者都要有**。

---

## 7. 收尾

> **"互锁不是写在按钮上的礼貌，是写在输出上的纪律：同一时刻只能有一个成立。"**
