# L0.2 起保停：第一个能跑的块

> 教练读这页的顺序：先让学员照第 1–5 步做完 → 让他自己填第 6 步的三条用例 → 按判据判分。
> **不要提前讲第 7 节的"为什么"**，那是他 FAIL 之后才给的提示。

---

## 0. 这节课要得到什么

一个按钮按一下，电机转起来；按另一个按钮，电机停。断电再上电，它不该自己转。

这就是几乎所有程序的第一块砖。学完你能说出：**为什么停止按钮要接常闭、为什么输出要并联自己的触点。**

---

## 1. 准备（两分钟）

| 你需要 | 说明 |
|---|---|
| 博途已装好 | 没有？先看 `L0-0-install.md`，别在这一步耗一天 |
| 一个空项目 | 不要用现场工程练，这是纪律 |
| 一个 CPU | **不需要真实硬件**。博途里加一台虚拟的 S7-1200 就能编译 |

**为什么必须加 CPU**：博途的项目必须先有设备才能编译 PLC 程序。空项目里直接建块，导入和编译都会失败（第 7 节有原文报错）。

---

## 2. 建项目 + 加 CPU

1. 打开博途 → **创建新项目**。
   - 项目名用英文：`Demo_StartStop`。
   - 路径**不要有中文和空格**（`D:\PLC\Demo_StartStop`）。这一条能省掉后面一半的怪问题。
2. 点 **添加新设备** → 控制器 → SIMATIC S7-1200 → CPU → **CPU 1214C DC/DC/DC**。
   - 订货号不用纠结，默认那个就行；版本选你博途里能选到的最高。
   - 提示"是否启用安全设置"之类，一路默认。
3. 加完后左侧项目树里应该出现 `PLC_1 [CPU 1214C DC/DC/DC]`，展开它能看到 **程序块 → Main [OB1]**。

> 版本差异：V19 / V20 / V21 的菜单文字略有不同，找不到就搜"添加新设备"。位置都在项目树最上面。

---

## 3. 先搞清三个名词（三十秒）

| 词 | 一句话 | 类比 |
|---|---|---|
| **OB1** | 主程序块，PLC 每个扫描周期都从头跑一遍 | 工厂的总调度，一圈一圈地转 |
| **扫描周期** | 读输入 → 跑一遍 OB1 → 写输出，这整个过程 | 心跳。一次心跳里程序只跑一遍 |
| **编译** | 把程序翻译成 CPU 能执行的东西，顺便检查错误 | 交卷前的检查 |

**这一课最关键的一句**：程序不是"执行一次就停"，是**每秒几百上千次从头跑一遍**。所以"输出保持"不是因为它被记住了，是因为**每一圈都被重新点亮了一次**。

---

## 4. 写梯形图（照抄）

双击 **Main [OB1]** 打开。上方工具栏选 **LAD**（梯形图）。

拖三个元件到第一个网络：

```text
       Start          Stop                      Run
──┤ ├──┬──────┬──┤/├──────────────────────────( )──
       │      │
       │  Run │
       └──┤ ├─┘
```

| 元件 | 在哪 | 参数 |
|---|---|---|
| 常开触点 `┤ ├` | 工具栏"位逻辑" | 上面填 `Start` |
| 常闭触点 `┤/├` | 同上 | 上面填 `Stop` |
| 线圈 `( )` | 同上 | 上面填 `Run` |
| 并联的常开触点 | 复制第一个，拖到 `Start` 下方，并联起来 | 填 `Run` |

填完会弹出"定义变量"的框，选 **全局变量 → PLC 变量 → 默认变量表**，三个都建 `Bool` 类型。名字就用 `Start` / `Stop` / `Run`。

**为什么叫"起保停"**：`Start` 是"起"，`Run` 并联回来叫"保"，`Stop` 是"停"。

---

## 5. 编译，看结果

右键 **程序块** → **编译** → **软件（全部重建）**。

下方"编译"窗口出现一行：

```text
0 错误, 0 警告
```

（英文界面是 `0 Errors, 0 Warnings`。）

**这时候不要急着下载**。先做第 6 步。

---

## 6. 你要交的东西（三条用例）

下载到仿真（工具栏"开始仿真"→ 启动 PLCSIM → 下载 → 转到在线），或者用云端仿真跑同一段逻辑。然后填这张表：

| # | 操作 | 期望 | 实际 | PASS/FAIL |
|---|---|---|---|---|
| 1 | `Start` 置 1，保持 1 秒，再置 0 | `Run` 一直是 1 | | |
| 2 | `Start` 置 0 后，`Run` 置 1（手动改 Run 不行，用 `Start` 重新触发） | 见下一行说明 | | |
| 3 | `Stop` 置 1 | `Run` 变 0 | | |
| 4 | `Stop` 回 0 后 | `Run` 保持 0（不会自己又起来） | | |

> 用例 2 的意思是：**别用 `Start` 的持续信号保持**。把 `Start` 松掉（置 0），`Run` 还应该是 1。这一条能抓出"忘了并联自锁"的人。

**判分只看这张表和编译结果，不看代码好不好看。**

## 7. 常见失败与提示（按顺序给，别一次全说）

| 现象 | 一级提示 | 二级提示 |
|---|---|---|
| 编译报"未定义变量" | 三个变量都在默认变量表里建了吗？ | 检查大小写，博途不区分大小写但拼错就不认 |
| `Start` 松开后 `Run` 掉了 | 看"保"这个字：谁负责把它留住？ | 把 `Run` 的触点并联到 `Start` 两边 |
| `Stop` 按了没反应 | 停止信号是"常开还是常闭"接进来的？ | `Stop` 应该用常闭触点 `┤/├` |
| `Stop` 松开后 `Run` 又起来了 | 你是在哪个周期判的？ | 停机后 `Start` 还是 1 吗？把 `Start` 置 0 再测 |
| 上电 `Run` 就是 1 | 变量是不是被设了保持？ | 检查变量属性里的"保持性" |

**三级提示（只在两级都试过之后给）**：完整正确写法——

```text
       Start          Stop                      Run
──┤ ├──┬──────┬──┤/├──────────────────────────( )──
       │      │
       └─┤ ├──┘   ← 这个触点填 Run
```

---

## 8. 三个"为什么"（PASS 之后再讲）

1. **为什么 `Stop` 用常闭？** 现场停止按钮一般是常闭接法：线断了 = 停。程序里用常闭触点，正常时通、按下时断，跟现场一致。用常开写反了，现场断线会变成"按不了停"。
2. **为什么并联 `Run`？** 因为按钮是点动。人松手信号就没了，程序每个周期都要重新判断"该不该转"，所以要用自己的输出去保持自己。
3. **为什么断电后不自己转？** 普通变量不保持，上电从 0 开始。**这是安全特性，不要为了"方便"改成保持型。**

> **"起保停不是三个元件，是两件事：用自锁记住'我要转'，用常闭保证'一按就停'。"**
